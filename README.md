# Tic-Tac-Toe

**[Spiel starten](https://xman-berlin.github.io/tic-tac-toe/)** — die Live-Version auf GitHub Pages.

Klassisches Drei-Gewinnt im Browser: ein einzelnes `index.html`, ohne Installation und ohne Server.

## Funktionen

- **1 Spieler gegen die KI** — du spielst als X, die KI als O. Die KI rechnet mit Minimax und Alpha-Beta und spielt fehlerfrei.
- **2 Spieler (Hotseat)** — beide spielen abwechselnd auf demselben Bildschirm.
- Gewinnlinie wird hervorgehoben; Unentschieden wird erkannt.
- Neu starten, Modus wechseln oder zurück ins Menü.
- Statusmeldungen auf Deutsch.

## So spielst du

1. Öffne die [Live-App](https://xman-berlin.github.io/tic-tac-toe/).
2. Wähle **1 Spieler** oder **2 Spieler**.
3. Tippe oder klicke ein freies Feld. Wer drei in einer Reihe hat (waagerecht, senkrecht oder diagonal), gewinnt. Ist das Feld voll und niemand hat drei, endet die Partie unentschieden.
4. Im 1-Spieler-Modus setzt die KI nach deinem Zug. Im Hotseat wechselt der Zug zwischen X und O.

Das Spiel läuft auf dem iPhone und iPad in Safari.

## Lokal starten

Datei `index.html` im Browser öffnen — ein Webserver ist nicht nötig.
